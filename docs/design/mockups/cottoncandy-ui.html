CottonCandy · UI

The GraceOS browser, drawn with the Grace Candyland tokens. Every frame on this page comes from one template and the same tokens, so the controls below change all of them at once. The live window is interactive: click tabs, the address bar, the site icon, Downloads, the menu and the sparkle, or press Ctrl+F or Esc inside it. Spec: docs/design/2026-10-20-cottoncandy-ui.md. Favicons are placeholders: the browser shows each site's real icon.
